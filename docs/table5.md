# 表 5 的有界枚举

在仓库根目录运行 `python scripts/table5.py`。脚本仅使用 Python 标准库，读取冻结协议和历史汇总，打印五个检查器的结果。计数与记录有差异时，程序以非零状态退出。

## 实验与来源

2026 年 11 月 11 日的事后实验 `artifact-aba-20261111-001` 从两个二值事实 x、y 和一份初始内容为 A 的已确认文档出发。每一步可以写入一个事实、写入文档或递增行政版本。长度 0 至 4 涵盖空序列以及七种操作的所有有序组合，共 1 + 7 + 49 + 343 + 2,401 = 2,801 条。每条序列分别在依赖声明完整和不完整时运行，合计 5,602 个序列与依赖层组合。表 5 只取完整依赖层。

- `protocols/table5.json` 是原枚举程序读入的协议文件，逐字节保留。协议中的源文件名指原实验的文件布局。
- `scripts/table5.py` 移植自研究程序 `exhaustive-benchmark/run.py` 和 `trace-benchmark/benchmark.py`。前者提供观察状态生成、历史敏感真值、补入文档修订戳后的检查器和枚举循环，后者提供前四个参考检查器。公开版保留这些计算，改为读取仓库内文件，直接累计表 5 的历史敏感结果与表注中的未知数。原实验也评估了当前内容契约。
- `results/table5.csv` 来自该实验的 `aggregate.json`。从 `rows` 筛取 `dependency_complete=true` 且 `contract=history_sensitive` 的五行，按记录顺序保留 `monitor, traces, valid, invalid, unsafe_accepts, benign_rejects, unknown`。原记录省略的 `unknown` 计数补为 0。源汇总文件的 SHA-256 为 `222a66b96a1069817ed68c7aee00ac13d19dae677dc6972b2adeef7bfdcdc9c2`。

## 判定与读数

历史敏感真值单独重放操作。任何实际事实或文档内容变化都会撤销原确认，即使后来恢复到初值。相同值重写与行政版本递增保留原确认。2,801 条序列中，341 条仍有效，2,460 条已经失效。误放指真值失效而检查器接受，误拒指真值有效而检查器拒绝。

| 检查器 | 误放 | 误拒 | 未知 |
| --- | ---: | ---: | ---: |
| 永不失效 | 2,460 | 0 | 0 |
| 全局版本相等 | 220 | 220 | 0 |
| 内容投影 | 348 | 0 | 0 |
| 事实修订戳＋文档摘要 | 110 | 0 | 0 |
| 事实与文档修订戳 | 0 | 0 | 0 |

依赖不完整时，内容投影及两种修订戳检查器各输出 2,801 个未知。研究者先识别了文档恢复初始内容的例子，再冻结有界枚举协议。上述计数适用于这七种操作、长度界限及无重新确认和并发的模型。表 3 的已知正控 B13 来自另一组后端局部更新实验。
